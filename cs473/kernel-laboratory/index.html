Equations & things to watch

Kernel shapes use their standard definitions: Gaussian K(u) = exp(−u²/2)/√(2π); uniform K(u) = ½ when |u| ≤ 1; Epanechnikov K(u) = ¾(1 − u²) when |u| ≤ 1. The last two are zero outside the window.

The same numeric h does not imply the same kernel variance: it is standard deviation for the Gaussian, but half the support width for uniform and Epanechnikov. Compare smoothing with this difference in mind.

These are one-dimensional examples. In D dimensions, KDE uses 1/(Nhᴰ). Small bandwidth can overfit; large bandwidth can erase real structure. Select bandwidth with validation rather than judging only the training fit.
