Core idea: mutual information is information shared by two variables. It is zero exactly when they are independent, and it can detect nonlinear dependence that ordinary correlation misses.

What the inequality says

Data processing inequality: processing cannot create new information about the original variable. The final copy Y cannot know more about X than the intermediate copy Z did.
Markov conditionp(y|x,z)=p(y|z)

Once Z is known, X gives no extra help for predicting Y.

InequalityX → Z → Y ⇒ I(X;Y) ≤ I(X;Z)

Equality is possible only when the processing loses no relevant information.
