    Second-order objective and notation

    ℓᵢ = aᵢ × ½(yᵢ − Fᵢ)², where aᵢ is observation weight, yᵢ is demand, and Fᵢ is the current prediction. Its gradient gᵢ = aᵢ(Fᵢ − yᵢ), and curvature hᵢ = aᵢ.

    The approximate objective for correction tree f is Σᵢ[gᵢf(xᵢ) + ½hᵢf(xᵢ)²] + ½λΣⱼwⱼ² + γT. A learned leaf weight wⱼ is a prediction correction, not an observation weight. T is the number of leaves; λ penalizes leaf weights and γ penalizes each leaf. η is the learning rate applied after fitting.

      What about correlated features?

      If temperature and building size are correlated, setting all temperatures to the same value while keeping each size can create combinations rarely seen in the original data. A PDP averages the fitted model’s predictions for those combinations; it does not establish a causal effect. ICE curves can show individual differences that an average hides.
