Boosting laboratory

Three ways to build an ensemble one small correction at a time.

All observations are fabricated, reproducible simulations. Models fit only the filled training points; outlined validation points measure performance and never enter fitting. One input feature makes the entire learned function visible.

Settings apply to all three trajectories. Change a setting to restart them.

Same idea, different fitting quantities

Current predictions → loss-derived fitting quantities → new learner → updated ensemble. A round adds one learner; a walkthrough stage exposes one calculation within that round. Round 3 means three learner additions in each model, not equal optimization progress.

AdaBoost’s σ(2F) is the probability mapping implied by exponential loss, not a claim of empirical calibration. Regression loss is in squared demand units; classification log loss is in nats. These scales are not comparable. Random forests fit independent trees; boosting fits sequential corrections.
