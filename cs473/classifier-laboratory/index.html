What is Bayesian about this model?

For each class and feature, θ starts with a Beta(α, β) distribution. After k presences in n examples, θ | data ~ Beta(α + k, β + n − k). The predictive probability is (k + α) / (n + α + β). We integrate the class-conditional likelihood over these independent posteriors, then normalize the joint predictive scores across classes. Class priors here are fixed at ½ by the balanced design.

These bars show predictions, not credible intervals for θ. MLE uses k / n. Bayesian predictions use prior evidence as well as observations. With α = β = 1, the predictive estimate is Laplace smoothing; it is not the MAP estimate.

See the fitted distributions and equations

Gaussian NB: p(x | c) = N(x₁ | μ₁c, σ²₁c) × N(x₂ | μ₂c, σ²₂c). Its covariance off the diagonal is zero.

Full Gaussian: p(x | c) = N(x | μc, Σc). Each class learns its own covariance, so the decision boundary can be curved (quadratic discriminant analysis).

Logistic regression: p(c = 1 | x) = sigmoid(b + w₁x₁ + w₂x₂). Its boundary is linear. Here it minimizes mean logistic loss with L2 penalty λ = 0.02 on standardized features; the intercept is unpenalized.

Gaussian variances receive a small +0.01 regularizer for numerical stability. Missing-feature calculations assume the missingness mechanism adds no class information.
