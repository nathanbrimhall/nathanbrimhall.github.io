Siamese & triplet training

Watch one shared network turn measurements into embeddings. Step through the loss and see a real gradient update move the data.

What changes between the methods? Both use Euclidean distance in the same embedding space. Siamese training uses labeled pairs with contrastive loss; triplet training uses an anchor, a positive, and a negative with a relative ranking loss.

Understand the equations and limitations

Siamese contrastive loss

Here s = 1 means matching and s = 0 means nonmatching. D is Euclidean distance.

L = sD² + (1 − s) max(0, m − D)²

Matching pairs are pulled together. Nonmatching pairs are pushed apart only while D < m. Matching-only training can collapse embeddings; negative examples are necessary to preserve distinctions.

Triplet loss

L = max(0, ‖zA − zP‖² − ‖zA − zN‖² + m)

Zero loss requires squared distance dAN ≥ dAP + m. The triplet margin is in squared-distance units. The contrastive margin is in ordinary-distance units; the same numeric margin is not an equivalent constraint.

Backpropagation

∇θ L = Σᵢ (∂zᵢ / ∂θ)ᵀ ∇zᵢ L, then θnew = θ − η ∇θ L

The sum combines all branches. At the hinge boundary the demo uses zero gradient. A zero loss gives zero gradient for that example. Large requested updates are halved if necessary to avoid increasing the selected loss; actual η is displayed after the update.

This is a small nonlinear neural network on 24 fabricated two-feature measurements, not an image model. It illustrates the same shared-weight learning mechanics used in much larger Siamese and triplet networks. Embeddings are not normalized in this demo. Embedding axes expand only if needed and do not shrink during a run; reset starts a new run.
