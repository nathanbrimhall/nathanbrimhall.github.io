    MORE FEATURES

    How many components should we keep?

    Six simulated sensor measurements are generated by two shared hidden factors plus noise. They are standardized before this PCA so the sensors share a common scale.

    Reveal how the six sensor features were generated

    For each part, draw two independent hidden factors A and B from a standard normal distribution. Sensor j is xⱼ = aⱼA + bⱼB + εⱼ, where εⱼ is independent normal noise with standard deviation 0.38. The loading pairs (aⱼ,bⱼ) are (1,.15), (.9,.25), (.8,−.15), (.1,1), (.2,.85), and (−.2,.8). Then standardize each sensor column before PCA. The two shared factors create correlations; the added noise prevents a perfectly two-dimensional dataset.

    Why use SVD? What are the matrix shapes?

    For centered data with N rows and D features, Xc is N×D. Its singular value decomposition is Xc = UΣVᵀ. Columns of V are the D-dimensional principal directions; singular values sⱼ give covariance eigenvalues λⱼ = sⱼ²/(N−1). This page uses a symmetric Jacobi eigensolver on the small D×D covariance matrix; it avoids matrix inversion. Tiny negative eigenvalues from rounding are treated as zero.

    For large datasets, randomized or incremental PCA can reduce computation or memory. Constant features carry no variance and standardize to zero.
