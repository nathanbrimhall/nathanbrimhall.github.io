Equations, numerical details, and limits

f ~ GP(m,k); y = f(X) + ε; ε ~ N(0,σn²I).

Kᵢⱼ = k(xᵢ,xⱼ), C = K + σn²I, r = y − m(X).

Cα = r; μ* = m(x*) + k*ᵀα; vf* = k(x*,x*) − k*ᵀC⁻¹k*.

vy* = vf* + σn²; pointwise interval = μ* ± 1.96√v.

The code factorizes C + δI = LLᵀ, solves Lb = r and Lᵀα = b, then solves Lv = k*. Variance is k(x*,x*) − vᵀv. Tiny jitter δ stabilizes arithmetic; it is displayed separately from measurement noise. Exact interpolation is approximate at floating-point precision with jitter.

Kernel hyperparameters are chosen by your controls, not automatically learned. Uncertainty can be misleading if the kernel, prior mean, or noise assumption is wrong. The models are unconstrained: a GP can predict physically impossible values, such as yield above 100%. These demos do not replace a domain model.

For a decaying kernel such as RBF or Matérn, predictions far from observed inputs approach the prior mean and variance. A periodic kernel can remain strongly related to distant inputs one period apart. A linear kernel extrapolates a trend.

Standard dense GP fitting costs roughly O(N³) time and O(N²) storage. This lab keeps N small so each matrix operation can be inspected.

What does each part do?

Kernel / covariance function

Encodes how function values at two inputs vary together. It describes the kinds of functions considered plausible. It is not a probability density and need not integrate to 1.

Mercer / positive semidefinite

A valid covariance kernel is symmetric and gives a PSD matrix for every finite input set: aᵀKa ≥ 0. This makes every linear combination of function values have a nonnegative variance. Individual entries may be negative.

Prior mean

The starting prediction before data. This lab uses a stated, fixed baseline for each scenario. Observations correct that baseline.

Noise-free versus noisy

Exact observations pin down the function at known inputs. Noisy measurements leave uncertainty about the underlying function, so the mean can smooth past observations.

Two uncertainties

Latent uncertainty concerns f(x*). A future measurement adds fresh sensor error: Var(y*) = Var(f*) + σn². Both have the same predicted mean.

Length and signal scales

The RBF/Matérn length scale sets how rapidly similarity declines with input distance. Signal standard deviation sets the prior vertical variation. The linear kernel’s ℓ controls slope variability; periodic ℓ is a dimensionless within-cycle smoothness parameter.

Kernel trick: k(x,x′) = φ(x)ᵀφ(x′). Under Mercer’s theorem’s regularity conditions, k(x,x′) = Σⱼ λⱼψⱼ(x)ψⱼ(x′), λⱼ ≥ 0. A feature map is φⱼ(x) = √λⱼψⱼ(x). A GP uses this valid kernel as covariance; a Gaussian distribution over linear feature weights produces the same covariance.
