What does the fitting step actually do?

The browser runs a deterministic sequential minimal optimization (SMO) solver for the soft-margin SVM dual. Each internal update adjusts two α values, preserves Σᵢαᵢyᵢ = 0, keeps 0 ≤ αᵢ ≤ C, and updates the intercept. The walkthrough shows the main learning stages, not each internal optimizer update.

maxα Σᵢαᵢ − ½ΣᵢⱼαᵢαⱼyᵢyⱼKᵢⱼ
subject to 0 ≤ αᵢ ≤ C and Σᵢαᵢyᵢ = 0.

This is training accuracy on a small fabricated sample, not test accuracy. A flexible kernel does not guarantee better generalization. Margins are measured in the selected feature space; their contours may be curved in the original inputs. An SVM score is not a probability.

What you need from each section

17.3.1 · Large margin classifiers

An SVM seeks a separating hyperplane with a large gap between classes. With labels y ∈ {−1,+1}, g(x) = wᵀφ(x) + b and prediction is sign(g(x)).

min ½‖w‖², subject to yᵢ(wᵀφ(xᵢ)+b) ≥ 1.

The boundary is g(x)=0. Margin planes are g(x)=±1. Their total distance in feature space is 2/‖w‖. Minimizing the weight norm maximizes this geometric margin when the constraints can be satisfied.

17.3.2 · The dual problem (skim)

Rewriting the optimization shows w = Σᵢαᵢyᵢφ(xᵢ). The data enter through inner products φ(xᵢ)ᵀφ(xⱼ). This is the key reason an SVM can use the kernel trick. You do not need the full dual derivation to understand the substitution.

17.3.3 · Soft margins (skim)

Allow slack ξᵢ ≥ 0 for margin violations:

min ½‖w‖² + CΣᵢξᵢ
subject to yᵢg(xᵢ) ≥ 1 − ξᵢ.

Equivalently, use hinge loss max(0,1 − yᵢg(xᵢ)). A correctly classified point can still have positive hinge loss if it is inside the margin. Larger C gives violations a larger penalty.

17.3.4 · The kernel trick (focus)

Define k(x,z) = φ(x)ᵀφ(z). Substitute this scalar for every feature-space inner product:

g(x) = Σᵢαᵢyᵢk(xᵢ,x) + b.

You can work as though the data had extra features without storing those feature vectors. The classifier remains linear in feature space; its boundary can be nonlinear in input space. A valid Mercer kernel is symmetric and produces PSD Gram matrices for every finite input set.

Linearφ(x) = (x₁,x₂); k(x,z) = xᵀz.

Polynomialφ(x) = (1,√2x₁,√2x₂,x₁²,√2x₁x₂,x₂²); k(x,z)=(1+xᵀz)².
RBFk(x,z)=exp(−γ‖x−z‖²). A corresponding feature space is infinite-dimensional. γ = 1/(2ℓ²).

The radius lift is an explanatory kernel, not the Gaussian RBF kernel. Both can draw curved boundaries, but they represent different feature spaces.
