Manifold learning explorer

Compare straight-line distances with paths along a rolled sheet, then see how different methods map the same points.

A sheet in three dimensions

A sensor reports three coordinates for each marked spot. Two hidden coordinates locate a spot on the ideal sheet, so its ambient dimension is 3 and its intrinsic dimension is 2. The manifold hypothesis suggests that some real data lies near a lower-dimensional shape.

Color indicates position along the sheet. The algorithms use the measured 3D coordinates only. Changes to k recompute the graph and its embedding.

    A map of approaches

    PCA retains variance in a flat projection. MDS places points to preserve supplied distances. Isomap uses graph paths to approximate distances along a manifold. LLE preserves local combinations of neighbors. Laplacian eigenmaps keep connected neighbors close. t-SNE emphasizes local similarities. Autoencoders learn compressed coordinates useful for reconstructing inputs.
